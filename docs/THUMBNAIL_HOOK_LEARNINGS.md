# Thumbnail-Hook learnings

Knowledge base for the Thumbnail-Hook rule (2026-10-30). Only **confirmed** findings go into
"Conclusions": each one cites the episodes and the analytics behind it. Forecasts and hunches stay out.

## How a row is added
After an episode has enough data (aim for at least 7 days and 1,000 impressions before reading CTR),
add one row per episode: chosen concept, CTR, retention at 30 s, average view duration, and the same
three for the median of the previous five long episodes. If an A/B test ran, record which cover won.
