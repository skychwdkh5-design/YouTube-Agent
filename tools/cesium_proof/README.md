# Cesium proof harness (CPU, free data only)
Local caching proxy + page + Playwright capture used for the Phase 2 visual gate. Not an episode renderer.
- `python3 server.py` serves `index.html`, proxies `/cesium/*` to cdn.jsdelivr.net (CesiumJS 1.120.0) and `/gibs/*` to NASA GIBS, caches under `./cache/` (create it).
- `node static.js '[{"cfg":"A","v":[lon,lat,range_m,heading_deg,pitch_deg],"out":"x.png"}]'` captures static frames (`cfg` A..D = GIBS layer sets in `index.html`). Needs global Playwright (`/opt/node22/lib/node_modules/playwright`).
- `run_frames.js N LIMIT_MS OFFSET STEP` captures `setFrame(u)` sequences to `frames/` (EP002 descent: 9000 km -> 41 km, heading 6->16.5 deg, nadir at the end; cfg E = Blue Marble + Landsat WELD with sea colour-keyed out). Run 3 offsets in parallel.
Results and verdict: `docs/KNOWN_LIMITATIONS.md`, `docs/RENDER_BENCHMARKS.md`.
`run_frames.js N LIMIT_MS OFFSET STEP FN OUTDIR WIDTH HEIGHT` is the generic capture (FN = `setFrame` or `setFrameA1`); it also writes `pNNNN.json` with anchored label positions from `window.proj()` (EP002 A1: Persian Gulf, UAE, Dubai). The viewport size is free (page uses 100vw/100vh). A capture worker can time out on page load; re-run its OFFSET alone.
V2 additions (EP002 A1, 2026-10-10): `setFrameA1v2(u)` = globe -> Dubai-centred zoom (target reaches Dubai by u=0.5, no desert transit). `run_frames_fast.js N LIMIT_MS OFFSET STEP FN OUTDIR W H DSF` waits for Cesium's own tile loading instead of forcing renders (4 s/frame instead of 30+ s). Pitfalls found: (1) never set `minimumLevel` on a `UrlTemplateImageryProvider` for a global layer, Cesium then requests hundreds of tiles per view (frames took 90 s+); (2) `server.py` now writes `.ct` first and the tile atomically (a race returned HTTP 500 for half-written tiles); (3) supersampling with `deviceScaleFactor` 1.5 is affordable only with the fast loop; never `pkill -f` a pattern that appears in your own command line (it kills the shell).
