# Videos

One folder per video, created from `channel/templates/` by `/geo-research`:

```
channel/videos/<slug>/
  brief.md   claims.md   script.md   visuals.md   package.md   seo.md   shorts.md   post.md
```

The slug is lowercase-hyphenated (`northwest-angle`). Files move through the pipeline in that order;
see `CLAUDE.md`.
