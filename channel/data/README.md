# Data

Exports the creator saves by hand from YouTube Studio. No API or OAuth connection is configured.

Suggested names:
- `<slug>-retention.csv` - Studio > video > Analytics > Engagement > audience retention > download
- `<slug>-overview.csv` - views, impressions, CTR, average view duration
- `channel-<YYYY-MM>.csv` - channel-level monthly export
- `competitors-<YYYY-MM-DD>.json` - collected list for `/yt-viral` (`swipe.py` format)

Do not put credentials, tokens or private viewer data in this folder.
