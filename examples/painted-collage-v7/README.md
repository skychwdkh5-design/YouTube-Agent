Run python build.py. Needs Pillow, numpy, FFmpeg with Flite/libx264/AAC and DejaVu Sans Bold. The NASA map is downloaded and SHA256-checked by build.py. Output OA_suez_painted_v7_15s.mp4 (15s, 1280x720, 30fps, H.264/AAC). Temporary local speech, not Adam. Independent painted raster props and a camera moving over a shared map; this is 2.5D compositing, not full 3D/facial rigging.

Art guide: docs/ORBITAL_ATLAS_VISUAL_STYLE.md. Production handoff: docs/PAINTED_VIDEO_HANDOFF.md. V6 temporal scene/camera/rewind structure is retained, with new painted assets and corrected atlas crop bounds. Full tests: representative keyframes reviewed, output duration/streams/decode checked.
