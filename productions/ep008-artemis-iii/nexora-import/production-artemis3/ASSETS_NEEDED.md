# Artemis III - NASA originals needed

All six are NASA photos/graphics (US federal work, not subject to US copyright; NASA guidelines: no implied endorsement, insignia not public domain, no current-astronaut likeness in promotional use - none of these show astronauts). Licence in media.json: `PD-US-Gov`. Rights page: https://www.nasa.gov/nasa-brand-center/images-and-media/

**Why they are not here:** this environment cannot reach nasa.gov, images.nasa.gov, images-assets.nasa.gov, Wikimedia or Flickr (proxy 403, checked 2026-10-30). Not found in the repo, its releases, the Claude Project or Google Drive.

**How to get them:** `~orig` links follow the images.nasa.gov pattern for the NASA ID shown on the page (if one returns 404, use Download -> Original on images.nasa.gov for that ID). Open the *file* link (or the page -> Download -> Original). Save as `productions/artemis3/assets/<slot>.jpg` (or attach in chat). Minimum: 1920 px on the side that fills the frame; for the two portrait photos (n1, n2) the original should be >= 1920 px **wide**.

**First 20-second test needs only n1 and n4.**
