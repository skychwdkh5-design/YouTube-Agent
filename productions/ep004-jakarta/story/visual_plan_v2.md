# EP004 visual plan v2 (2.5-D V2C) - replaces the ESA map; no EVIDENCE MAP PENDING in the video
Rule: every frame carries a class chip. REAL SATELLITE = Landsat pixels we processed; DATA CARD = our own typography of a published number with source + period;
ILLUSTRATION = our own drawing/2.5-D animation. Illustrations are never shown as satellite evidence; no ESA frame is used (licence not needed, none distributed).

## Own base map (safe replacement for the ESA map)
Landsat 8 OLI 2026-09-14 (LC08_L1TP_122064_20260914_20260924_02_T1, cloud 3 %) and Landsat 5 TM 1990-07-09 (LT05_L1TP_122064_19900709_20200915_02_T1, cloud 4 %),
re-fetchable with USGS M2M (checked reachable 2026-10-16), co-registered on one UTM 48S grid (yt-geo), Natural Earth (public domain) for the locator.
Used for: where Jakarta is, the coast, the harbour, 1990 -> 2026 wipe (honest: same grid), named places. Labels "TANJUNG PRIOK" and "PIK2 COAST" mark PLACES NAMED IN THE
STUDY, with the chip "AREA NAMED IN THE STUDY - EXTENT NOT SHOWN"; no velocity colours, no measured extent and no uplift are drawn anywhere.
A measured velocity map is possible only from CC-licensed raster data: Zenodo 10.5281/zenodo.19456870 and cdn.ncbi.nlm.nih.gov are blocked here - allowlist them (or send the files) to add one.
